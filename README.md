# embr — landing page

Static landing page for **embr**: _Every PR. A live environment._

## Local preview

Just open `index.html` in a browser, or serve it locally:

```sh
python -m http.server 8000
# → http://localhost:8000
```

## Deployment

This site is deployed as a static site via **GitHub Pages** from the `main` branch.

Live URL: https://spellegrino021.github.io/embr-landing/
